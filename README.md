# PopChat for Twitch

Twitchのポップアウトにチャットを追加します。

PopChat for Twitch 1.6.0は、ライブ配信の映像と公式チャットをまとめて表示するブラウザ拡張機能です。アーカイブでは、公式チャットリプレイ付きの通常別窓を開けます。

## 主な機能

- ライブ配信の純正ポップアウトに公式チャットを追加
- 通常の配信ページの歯車メニューから、映像とチャットの最前面小窓を起動
- アーカイブの歯車メニューから、現在位置付きの公式ページをチャットリプレイと一緒に別窓で表示
- AUTO / SIDE / BOTTOM / HIDEでチャットを右側・下側・非表示に切り替え
- 11言語の表示、キーボード操作、端末内への表示設定の保存

Twitch本来のポップアウト項目は変更しません。初回の「使い方・設定」で説明を確認し、有効にしてから動作します。

## 使い方

[導入と操作方法](docs/INSTALL.md) · [アーカイブの使い方](docs/VOD-PREVIEW.md) · [各言語の説明](docs/locales/)

デスクトップ版Chrome / Edgeを対象とします。ライブの最前面表示にはDocument Picture-in-Picture対応が必要です。アーカイブは通常別窓のみで、最前面表示には対応していません。Firefox、モバイル、クリップは対象外です。

1.6.0は実環境で基本動作の確認報告があります。自動検査441件と静的検査は成功していますが、幅広い環境でのシーク・再生速度変更・長時間のリプレイ同期を網羅した確認ではありません。[検証範囲](docs/TESTING.md)

## プライバシー

設定と有効化への同意記録を端末内に保存します。開発者向けのデータ送信、解析SDK、チャット本文や閲覧履歴の保存はありません。映像・公式チャット・チャットリプレイの表示はTwitchと通信します。[プライバシーポリシー](PRIVACY.md)

## 開発

Node.js 20以上とPython 3を使用します。追加の依存パッケージは不要です。

```sh
npm test
npm run check
npm run package
```

実行用ZIPとソースZIPはdist/に生成されます。
