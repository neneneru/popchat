# 変更履歴

## 1.6.0 · 2026-10-15

- アーカイブの公式チャットリプレイ付きポップアウトを追加。歯車メニューから現在位置付きのTwitch公式ページを別窓で開き、元動画を一時停止します。
- アーカイブにもライブと共通の36pxヘッダーと24pxの配置ボタンを使用。AUTO / SIDE / BOTTOM / HIDE、狭幅表示、読み上げラベル、キーボード操作に対応します。
- アーカイブでは公式プレイヤーとネイティブのリプレイを同じページ内に保ちます。最前面表示、チャットだけの別窓、チャット再読込には対応していません。
- Twitchのブラジルポルトガル語メニュー「Pop-out de reprodução」の認識に対応しました。既知の構造・表示状態・一意性の確認は引き続き行います。
- アーカイブの案内とエラー表示を11言語に追加。プライバシーポリシーと操作説明を更新しました。
- 同意管理、ライブ配信の通常ポップアウト・最前面小窓、配置設定を維持。権限の追加はありません。
- 自動検査441件と静的検査が成功。実環境で基本動作の確認報告があります。幅広いシーク・再生速度変更・長時間同期の実サービス検証は未完了です。

## 1.5.1 · 2026-10-06

- 初回インストール時に説明・同意ページを専用タブで一度だけ表示。
- 白基調の読みやすいページへ整理し、同意の説明・使い方・備考を分離。
- ツールバーのポップアップは現在の状態と「使い方・設定」に簡素化。
- 日本語の短い説明を「Twitchのポップアウトにチャットを追加します。」へ変更し、11言語も同等の簡潔な表現へ統一。
- 更新・再起動では説明タブを自動表示せず、既存の同意・表示設定を保持。
- 権限と保存項目、歯車内だけの最前面入口、36pxヘッダー、24pxボタン、アイコンを維持。
