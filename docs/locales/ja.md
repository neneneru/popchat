# PopChat for Twitch

Twitchが提供・公認するものではない、非公式の拡張機能です。

## ローカル版の導入

1. 配布用／ストア用ZIPを専用のフォルダーに展開します。ZIP直下に `manifest.json` があります。
2. Chromeは `chrome://extensions`、Edgeは `edge://extensions` を開き、デベロッパーモードをONにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、展開先のフォルダー自体を選びます。ソース版ZIPを使う場合は、展開したソース内の `popchat-for-twitch/extension` を選びます。いずれも `manifest.json` が直接入っているフォルダーを指定してください。
4. 初回インストール時は、拡張機能内の案内ページが新しいタブで自動的に開きます。説明を確認し、同意いただける場合は「有効にする」を押します。「今はしない」を選ぶと、無効のままにできます。
5. 必要に応じてTwitchページを再読み込みします。

ツールバーの拡張アイコンでは、有効・無効の状態を確認できます。「使い方・設定」を押すと専用ページが開き、すでに開いている場合はそのタブに戻ります。このページから、いつでも有効化や無効化ができます。

## 使い方

Twitchの配信ページで、プレイヤーの歯車アイコンをクリックします。「ポップアウト」で通常の小窓を、「ポップアウト（最前面）」で最前面の小窓を開きます。小窓の上部で、チャットの配置を選びます。

AUTOはウィンドウに合わせて自動配置、SIDEは右側、BOTTOMは下側にチャットを表示します。HIDEはチャットの読み込み状態を保持して非表示にし、ほかの配置を選ぶと再表示します。「再読込」は公式チャットを再読み込みし、「別窓」は公式チャットだけを別ウィンドウで開きます。

最前面の小窓を使う間は、元のTwitchタブを開いたままにしてください。元のタブを閉じる、再読み込みする、別のページに移動すると、小窓も閉じます。小窓を閉じると、映像が元のタブに戻ります。

## 対象と制約

対象はDocument Picture-in-Pictureに対応するデスクトップ版Chrome / Edge（Chromium 116以降）です。モバイル、Firefox、VOD、クリップは対象外です。認識できるTwitchのメニュー構造にだけ項目を追加するため、Twitchの変更で項目が出なくなる場合があります。元タブを閉じる・再読み込み・別ページへ移動すると、最前面小窓も閉じます。Twitch独自の設定やオーバーレイの一部は小窓へ移りません。チャットのログイン・投稿はTwitchとブラウザ設定に依存します。

最前面の小窓にはDocument Picture-in-Pictureを使います。通常の動画専用PiPにチャットを追加する機能ではありません。

## プライバシー

有効にした後、現在のチャンネルURLと既存の動画要素・プレイヤーやメニューの構造を端末内で処理し、映像とチャットを配置します。公式チャットはTwitchへ直接接続し、Twitchのログイン状態を使う場合があります。表示設定と同意の記録だけを端末内に保存し、開発者へのデータ送信はありません。

有効にするまでは、チャンネルURLやプレイヤー・メニューの構造を読み取らず、公式チャットも読み込みません。ツールバーの拡張アイコンから「使い方・設定」を開き、専用ページで「無効にする」を押すと、同意を取り消せます。拡張が管理する埋め込みチャットと最前面の小窓を閉じて映像を元に戻し、表示設定は保持します。

この拡張には解析・広告・独自サーバーはありません。現在のURLからチャンネル名を読み、同じチャンネルの公式チャットを表示するためだけに使用します。ローカル拡張ストレージに保存するのは表示モード、小窓の幅・高さ、同意の記録のみで、同期はしません。チャット、閲覧履歴、チャンネル名、ユーザー名、認証情報、Cookieは保存せず、公式チャットiframe内の本文も読み取りません。Twitchの公式埋め込みはTwitchへ直接接続し、ブラウザが許可する範囲でTwitchのログイン状態を使用します。ログインとチャットはTwitch自身のポリシーに従って処理されます。権限はstorageのみで、対象はwww.twitch.tvとplayer.twitch.tvのHTTPSページです。

## 更新

小窓を閉じ、ブラウザに登録した読み込み先と同じパスで、フォルダー全体を新版に入れ替えます。古いフォルダーへの追加上書きはしないでください。その後、拡張機能管理画面で拡張を再読み込みし、開いているTwitchページもすべて再読み込みします。通常の更新では保存済みの表示設定を引き継ぎます。

更新時やブラウザ起動時に案内ページは自動で開きません。バージョン1.5.0で保存した同意の状態も引き継ぎます。以前の表示設定だけでは、自動的に同意したことにはなりません。同意確認のなかった旧版から更新した場合は、ツールバーの拡張アイコンから「使い方・設定」を開き、説明を確認して「有効にする」を押してからお使いください。
