# PopChat for Twitch

Неофициальное расширение, не предоставленное и не одобренное Twitch.

## Установка локального пакета

1. Распакуйте установочный ZIP для запуска/магазина в отдельную папку. `manifest.json` находится в корне ZIP.
2. Откройте `chrome://extensions` в Chrome или `edge://extensions` в Edge и включите режим разработчика.
3. Выберите «Загрузить распакованное расширение» и саму распакованную папку. Если используете ZIP с исходниками, выберите `popchat-for-twitch/extension` внутри распакованного пакета. В обоих случаях нужна папка, непосредственно содержащая `manifest.json`.
4. При первой установке локальная страница расширения автоматически открывается в новой вкладке. Прочитайте информацию и выберите «Включить», если согласны. Выберите «Не сейчас», чтобы оставить расширение отключённым.
5. При необходимости обновите страницы Twitch.

Всплывающее окно расширения на панели инструментов показывает, включено ли оно. Выберите «Справка и настройки», чтобы открыть отдельную страницу или вернуться к её вкладке, если она уже открыта. На этой странице можно в любое время включить или отключить функции.

## Использование

### Прямые трансляции

На странице прямой трансляции Twitch нажмите значок шестерёнки в плеере. Выберите «Отдельное окно» для обычного окна или «Отдельное окно (поверх всех)» для окна поверх остальных. Выберите расположение чата в верхней части маленького окна.

AUTO выбирает расположение по форме окна; SIDE размещает чат справа; BOTTOM — под видео; HIDE скрывает чат, сохраняя его загруженным. Выберите другой режим, чтобы снова показать чат. «Обновить» перезагружает официальный чат. «Окно чата» открывает только официальный чат отдельно.

Не закрывайте исходную вкладку Twitch, пока используете окно поверх остальных. Если закрыть, обновить или открыть другую страницу в исходной вкладке, маленькое окно тоже закроется. Когда вы закроете маленькое окно, видео вернётся в исходную вкладку.

### Записи трансляций (VOD, версия 1.6.0)

На официальной странице записи Twitch откройте настройки плеера с помощью значка шестерёнки и выберите «Отдельное окно с повтором чата». В обычном окне откроется официальная страница видео с текущей позиции воспроизведения, с плеером Twitch и повтором чата. Исходная вкладка остаётся открытой, а её видео ставится на паузу. При закрытии окна позиция воспроизведения не переносится автоматически в исходную вкладку, и видео в ней не возобновляется автоматически.

AUTO, SIDE, BOTTOM и HIDE работают и для повтора чата. VOD поддерживают только обычные окна; режим поверх всех окон недоступен. На панели VOD нет кнопок «Обновить» и «Окно чата». Доступность повтора чата и поведение воспроизведения зависят от Twitch.

## Совместимость и ограничения

Для настольных Chrome и Edge (Chromium 116 и новее). Для прямых трансляций в окне поверх остальных требуется Document Picture-in-Picture; для обычных окон VOD эта функция не нужна. Мобильные устройства, Firefox и клипы не поддерживаются. Пункт добавляется только при распознавании структуры меню Twitch; после обновления Twitch он может исчезнуть. Закрытие, обновление или переход на другую страницу в исходной вкладке закрывает окно поверх других окон. Некоторые настройки и элементы поверх видео в плеере Twitch не перемещаются вместе с видео. Вход в чат и отправка сообщений зависят от Twitch и настроек браузера.

Окно поверх остальных использует Document Picture-in-Picture. Эта функция не добавляет чат в обычный PiP, предназначенный только для видео.

## Конфиденциальность

После включения расширение локально использует URL текущего канала или видео, текущую позицию воспроизведения, существующий элемент видео и структуру плеера и меню для размещения видео и чата. Официальный чат подключается напрямую к Twitch и может использовать ваш сеанс входа в Twitch. Локально сохраняются только настройки отображения и запись о согласии. Данные разработчику не отправляются.

До включения расширение не читает URL канала или видео, позицию воспроизведения или структуру плеера и меню и не загружает официальный чат. Откройте «Справка и настройки» во всплывающем окне расширения на панели инструментов и выберите «Отключить» на отдельной странице, чтобы отозвать согласие. Встроенный чат и окно поверх остальных, которыми управляет расширение, закроются, а видео вернётся на место. Настройки отображения сохранятся.

Расширение не содержит аналитики и рекламы и не использует собственный сервер. Для прямых трансляций оно читает имя канала из текущего URL только для отображения соответствующего официального чата. В локальном хранилище расширения сохраняются только режим расположения, ширина и высота окна и запись о согласии, без синхронизации. Чаты, история просмотра, имена каналов и пользователей, учётные данные и cookie не сохраняются. Содержимое встроенного официального чата не читается. Официальные встроенные элементы Twitch соединяются напрямую с Twitch и используют его сеанс входа, если браузер это разрешает. Twitch обрабатывает вход и чат по своим правилам. Расширение использует только разрешение storage и работает на HTTPS-страницах www.twitch.tv и player.twitch.tv.

Для VOD идентификатор видео и текущая позиция воспроизведения используются, чтобы открыть официальную страницу записи Twitch. Расширение размещает существующий плеер Twitch и повтор чата без дополнительных запросов к API Twitch и без чтения сообщений повтора чата. Данные разработчику не отправляются. При отключении расширения в открытом окне VOD восстанавливается обычное расположение элементов; сама официальная страница Twitch остаётся открытой.

## Обновление

Оставляйте включённой только одну версию PopChat. Отключите старые или дублирующие установки перед включением обновлённой версии, затем обновите все открытые страницы Twitch.

Закройте маленькое окно. Замените загруженную папку целиком по тому же пути, который зарегистрирован в браузере, не смешивая новые файлы со старыми. Перезагрузите расширение в менеджере расширений браузера, затем обновите все открытые страницы Twitch. При обычном обновлении сохранённые настройки расположения остаются.

При обновлении и запуске браузера страница справки не открывается автоматически. Ваш выбор о согласии, сохранённый в версии 1.5.0, также сохраняется. Сами по себе сохранённые настройки отображения не означают согласия. При обновлении с версии без запроса согласия откройте «Справка и настройки» во всплывающем окне расширения на панели инструментов, прочитайте информацию и выберите «Включить», прежде чем использовать функции.
