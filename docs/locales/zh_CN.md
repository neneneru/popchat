# PopChat for Twitch

本扩展为非官方扩展，并非由 Twitch 提供或认可。

## 安装本地软件包

1. 将运行版／商店版 ZIP 解压到单独的文件夹中。`manifest.json` 位于 ZIP 根目录。
2. 在 Chrome 中打开 `chrome://extensions`，或在 Edge 中打开 `edge://extensions`，然后启用开发者模式。
3. 选择“加载已解压的扩展程序”，并选中解压后的文件夹本身。如果使用源码 ZIP，则选择解压后源码包内的 `popchat-for-twitch/extension`。两种情况都应选择直接包含 `manifest.json` 的文件夹。
4. 首次安装时，扩展自带的本地说明页面会在新标签页中自动打开。请阅读说明，如您同意，请选择“启用”。选择“暂不启用”则保持停用状态。
5. 如有需要，重新加载 Twitch 页面。

工具栏中的扩展弹出窗口会显示启用状态。选择“使用方法与设置”可打开专用页面；如果该页面已打开，则切换到已有标签页。您可以随时在此页面启用或停用功能。

## 使用方法

### 直播

在 Twitch 直播频道页面，点击播放器的齿轮图标。选择“弹出播放器”打开普通小窗口，或选择“弹出播放器（置顶）”打开置顶小窗口。在小窗口顶部选择聊天布局。

AUTO 根据窗口自动布局；SIDE 将聊天放在右侧；BOTTOM 将聊天放在视频下方；HIDE 隐藏聊天，同时保持其已加载状态。选择其他模式即可恢复显示。“重新加载”刷新官方聊天，“独立窗口”仅将官方聊天单独打开。

使用置顶小窗口时，请保持原 Twitch 标签页打开。关闭、重新加载原标签页或跳转到其他页面时，小窗口也会关闭。关闭小窗口后，视频会返回原标签页。

### 历史直播视频（VOD，版本 1.6.0）

在 Twitch 官方历史直播视频页面，点击播放器的齿轮图标，选择“弹出播放器（含聊天回放）”。扩展会在普通窗口中打开指定了当前播放位置的 Twitch 官方视频页面，并直接使用 Twitch 的播放器和聊天回放。原标签页保持打开，视频会暂停。关闭弹出窗口后，该窗口的播放位置不会自动同步回原标签页，原视频也不会自动恢复播放。

聊天回放同样支持 AUTO、SIDE、BOTTOM 和 HIDE。VOD 仅支持普通窗口，不支持置顶窗口。VOD 工具栏没有“重新加载”或“独立窗口”按钮。聊天回放是否可用及播放行为取决于 Twitch。

## 适用范围与限制

适用于桌面版 Chrome 和 Edge（Chromium 116 或更高版本）。直播置顶窗口需要 Document Picture-in-Picture，VOD 普通窗口则不需要。不支持移动设备、Firefox 和剪辑。扩展仅在识别出 Twitch 菜单结构时添加菜单项，Twitch 更新后该菜单项可能不再显示。关闭、重新加载原标签页或在其中跳转至其他页面，都会关闭置顶窗口。Twitch 播放器的部分设置和叠加界面不会随视频一起移动。聊天登录和发送消息取决于 Twitch 及浏览器设置。

置顶小窗口使用 Document Picture-in-Picture。本功能不会为普通的纯视频画中画添加聊天。

## 隐私

启用后，在本地处理当前频道或视频 URL、当前播放位置、现有视频元素及播放器和菜单结构，以排列视频与聊天。官方聊天直接连接 Twitch，可能使用您的 Twitch 登录状态。仅在本地保存显示设置和同意记录，不向开发者发送任何数据。

启用前，扩展不会读取频道或视频 URL、播放位置或播放器、菜单结构，也不会加载官方聊天。从工具栏的扩展弹出窗口打开“使用方法与设置”，在专用页面选择“停用”即可撤回同意。扩展会关闭其管理的嵌入式聊天和置顶小窗口，并将视频恢复到原位置，同时保留显示设置。

本扩展没有分析、广告或独立服务器。直播模式下，扩展仅从当前页面 URL 中读取频道名称，用于显示对应的官方聊天。本地扩展存储中仅保存布局模式、窗口宽高和同意记录，不进行同步。不保存聊天、浏览历史、频道名称、用户名、凭据或 Cookie，也不读取官方聊天框架内的内容。Twitch 官方嵌入内容直接连接 Twitch，并在浏览器允许时使用 Twitch 的登录会话。登录和聊天由 Twitch 按其自身政策处理。仅使用 storage 权限，运行范围为 www.twitch.tv 和 player.twitch.tv 的 HTTPS 页面。

VOD 模式使用视频 ID 和当前播放位置打开 Twitch 官方历史直播视频页面。扩展只调整 Twitch 现有播放器和聊天回放的布局，不额外调用 Twitch API，不读取聊天回放正文，也不向开发者发送数据。停用扩展后，已打开的 VOD 弹出窗口会恢复普通布局，Twitch 官方页面本身仍保持打开。

## 更新

请只启用一个版本的 PopChat。先停用旧版或重复安装的版本，再启用更新后的版本，然后重新加载所有已打开的 Twitch 页面。

关闭小窗口，在浏览器已注册的原加载路径中整体替换文件夹，不要将新文件合并覆盖到旧文件夹中。随后在浏览器扩展管理页面中重新加载扩展，并重新加载所有已打开的 Twitch 页面。正常更新会保留已保存的布局设置。

更新时或浏览器启动时，说明页面不会自动打开。版本 1.5.0 中保存的同意状态也会保留。仅有原先的显示设置不代表您已同意。如果从没有同意提示的旧版升级，请从工具栏的扩展弹出窗口打开“使用方法与设置”，阅读说明并选择“启用”后再使用功能。
