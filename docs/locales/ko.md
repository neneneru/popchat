# PopChat for Twitch

Twitch에서 제공하거나 공인하지 않은 비공식 확장 프로그램입니다.

## 로컬 패키지 설치

1. 배포용/스토어용 ZIP 파일을 별도의 폴더에 압축 해제합니다. `manifest.json`은 ZIP의 최상위에 있습니다.
2. Chrome에서 `chrome://extensions`, Edge에서 `edge://extensions`를 열고 개발자 모드를 켭니다.
3. “압축해제된 확장 프로그램을 로드합니다”를 선택하고 압축을 푼 폴더 자체를 엽니다. 소스 ZIP을 사용한다면 압축을 푼 소스 패키지 안의 `popchat-for-twitch/extension`을 선택합니다. 두 경우 모두 `manifest.json`이 바로 들어 있는 폴더를 선택하세요.
4. 처음 설치하면 확장 프로그램 내부의 안내 페이지가 새 탭으로 자동으로 열립니다. 안내를 확인하고 동의하시면 “활성화”를 선택하세요. “지금은 안 함”을 선택하면 비활성화 상태로 유지됩니다.
5. 필요한 경우 Twitch 페이지를 새로고침합니다.

도구 모음의 확장 프로그램 팝업에서 활성화 상태를 확인할 수 있습니다. “사용 방법 및 설정”을 선택하면 전용 페이지가 열리며, 이미 열려 있으면 해당 탭으로 돌아갑니다. 이 페이지에서 언제든지 기능을 활성화하거나 비활성화할 수 있습니다.

## 사용 방법

Twitch 생방송 채널 페이지에서 플레이어의 톱니바퀴 아이콘을 클릭하세요. “팝아웃”을 선택하면 일반 창이, “팝아웃 (항상 위)”을 선택하면 항상 위에 표시되는 창이 열립니다. 작은 창 상단에서 채팅 배치를 선택하세요.

AUTO는 창에 맞게 자동 배치하고, SIDE는 오른쪽, BOTTOM은 영상 아래에 채팅을 표시합니다. HIDE는 채팅을 로드한 상태로 숨기며, 다른 모드를 선택하면 다시 표시합니다. “새로고침”은 공식 채팅을 다시 로드하고 “별도 창”은 공식 채팅만 별도의 창으로 엽니다.

항상 위에 표시되는 창을 사용하는 동안 원래 Twitch 탭을 열어 두세요. 원래 탭을 닫거나 새로고침하거나 다른 페이지로 이동하면 작은 창도 닫힙니다. 작은 창을 닫으면 영상이 원래 탭으로 돌아갑니다.

## 지원 범위와 제한

Document Picture-in-Picture를 지원하는 데스크톱 Chrome과 Edge(Chromium 116 이상)를 대상으로 합니다. 모바일, Firefox, VOD, 클립은 지원 대상이 아닙니다. 인식할 수 있는 Twitch 메뉴 구조에서만 항목이 추가되므로 Twitch가 변경되면 항목이 나타나지 않을 수 있습니다. 원래 탭을 닫거나 새로고침하거나 다른 페이지로 이동하면 항상 위에 표시되는 창도 닫힙니다. Twitch 플레이어의 일부 설정과 오버레이는 영상과 함께 이동하지 않습니다. 채팅 로그인과 전송은 Twitch 및 브라우저 설정에 따라 달라집니다.

항상 위에 표시되는 창에는 Document Picture-in-Picture를 사용합니다. 일반적인 영상 전용 PiP에 채팅을 추가하는 기능은 아닙니다.

## 개인정보

활성화한 뒤 현재 채널 URL, 기존 영상 요소, 플레이어와 메뉴 구조를 기기 내에서 처리해 영상과 채팅을 배치합니다. 공식 채팅은 Twitch에 직접 연결하며 Twitch 로그인 상태를 사용할 수 있습니다. 표시 설정과 동의 기록만 기기에 저장하고, 개발자에게 데이터를 보내지 않습니다.

활성화하기 전에는 채널 URL이나 플레이어·메뉴 구조를 읽지 않고 공식 채팅도 불러오지 않습니다. 도구 모음의 확장 프로그램 팝업에서 “사용 방법 및 설정”을 열고 전용 페이지에서 “비활성화”를 선택하면 동의를 철회할 수 있습니다. 확장 프로그램이 관리하는 내장 채팅과 항상 위에 표시되는 창을 닫고 영상을 원래 위치로 돌려놓으며, 표시 설정은 유지합니다.

이 확장 프로그램에는 분석, 광고, 자체 서버가 없습니다. 현재 페이지 URL에서 채널 이름을 읽어 해당 채널의 공식 채팅을 표시하는 데만 사용합니다. 로컬 확장 프로그램 저장소에는 배치 모드, 창의 너비·높이, 동의 기록만 저장하며 동기화하지 않습니다. 채팅, 방문 기록, 채널 이름, 사용자 이름, 인증 정보, 쿠키를 저장하지 않으며 공식 채팅 프레임의 내용도 읽지 않습니다. Twitch 공식 임베드는 Twitch에 직접 연결하며, 브라우저가 허용하는 경우 Twitch 로그인 세션을 사용합니다. 로그인과 채팅은 Twitch의 정책에 따라 처리됩니다. storage 권한만 사용하며 www.twitch.tv와 player.twitch.tv의 HTTPS 페이지에서 실행됩니다.

## 업데이트

작은 창을 닫고, 브라우저에 등록된 경로에서 로드한 폴더 전체를 새 버전으로 교체하세요. 기존 폴더에 파일을 추가로 덮어쓰지 마세요. 확장 프로그램 관리 화면에서 확장 프로그램을 새로고침한 다음, 열려 있는 모든 Twitch 페이지도 새로고침하세요. 일반 업데이트 시 저장된 배치 설정은 유지됩니다.

업데이트하거나 브라우저를 시작할 때는 안내 페이지가 자동으로 열리지 않습니다. 버전 1.5.0에서 저장한 동의 상태도 유지됩니다. 기존 표시 설정만으로는 동의로 간주되지 않습니다. 동의 확인이 없던 이전 버전에서 업데이트한 경우, 도구 모음의 확장 프로그램 팝업에서 “사용 방법 및 설정”을 열고 안내를 확인한 뒤 “활성화”를 선택하세요.
