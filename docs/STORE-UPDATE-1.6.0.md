# Store overview addition: 1.6.0

Append the matching language block below to the existing store overview. Keep the existing overview; this addition does not replace it.

既存のストア概要の末尾に、該当する言語の追記を追加してください。既存の概要は残し、この追記で置き換えないでください。

日本語 (ja)
1.6.0
・アーカイブ動画にも対応しました。
 - ライブ配信では最前面も指定できますが、アーカイブ動画では技術的な理由により通常ウィンドウのみ指定可能です。
 - プレイヤーの設定の歯車アイコンから、「ポップアウト（チャットリプレイ付き）」を選ぶと利用可能です。

English (en)
1.6.0
・Archived videos are now supported too.
 - For live streams, you can also choose an always-on-top window, but archived videos are limited to regular windows for technical reasons.
 - To use this feature, open the player settings with the gear icon and select “Pop out with replay chat”.

한국어 (ko)
1.6.0
・지난 방송 영상도 지원합니다.
 - 실시간 방송에서는 항상 위에 표시되는 창도 선택할 수 있지만, 지난 방송 영상은 기술적인 이유로 일반 창만 선택할 수 있습니다.
 - 플레이어 설정의 톱니바퀴 아이콘을 누르고 “채팅 다시보기와 함께 팝아웃”을 선택하면 사용할 수 있습니다.

简体中文 (zh_CN)
1.6.0
・现已支持历史直播视频。
 - 直播还可以选择置顶窗口，但由于技术原因，历史直播视频仅支持普通窗口。
 - 点击播放器设置的齿轮图标，选择“弹出播放器（含聊天回放）”即可使用。

Español (es)
1.6.0
・Ahora también se admiten vídeos archivados.
 - En las emisiones en directo también puedes elegir una ventana siempre en primer plano, pero, por motivos técnicos, los vídeos archivados solo admiten ventanas normales.
 - Para usar esta función, abre los ajustes del reproductor con el icono de engranaje y elige “Abrir en otra ventana con repetición del chat”.

Deutsch (de)
1.6.0
・Archivierte Videos werden jetzt ebenfalls unterstützt.
 - Bei Livestreams kannst du auch ein Fenster wählen, das immer im Vordergrund bleibt. Archivierte Videos lassen sich aus technischen Gründen nur in normalen Fenstern öffnen.
 - Öffne die Player-Einstellungen über das Zahnradsymbol und wähle „Popout mit Chat-Wiedergabe“, um die Funktion zu nutzen.

Français (fr)
1.6.0
・Les vidéos archivées sont désormais également prises en charge.
 - Pour les diffusions en direct, vous pouvez aussi choisir une fenêtre toujours au premier plan. Pour les vidéos archivées, seules les fenêtres classiques sont disponibles pour des raisons techniques.
 - Pour utiliser cette fonction, ouvrez les paramètres du lecteur via l’icône d’engrenage et choisissez « Ouvrir dans une fenêtre avec rediffusion du chat ».

Português do Brasil (pt_BR)
1.6.0
・Agora também há suporte a vídeos arquivados.
 - Em transmissões ao vivo, também é possível escolher uma janela sempre no topo. Para vídeos arquivados, apenas janelas comuns estão disponíveis por motivos técnicos.
 - Para usar este recurso, abra as configurações do player pelo ícone de engrenagem e escolha “Abrir em outra janela com replay do chat”.

Русский (ru)
1.6.0
・Теперь поддерживаются и записи трансляций.
 - Для прямых трансляций также можно выбрать окно поверх всех остальных, но для записей трансляций по техническим причинам доступны только обычные окна.

العربية (ar)
