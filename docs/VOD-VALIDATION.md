# アーカイブ対応の検証範囲 · 1.6.0

日付: 2026-10-15

## 対応範囲

- 歯車メニューから、現在位置付きの公式アーカイブページを通常別窓で開きます。起動に成功したら元動画を一時停止します。
- 同じページ上のTwitch公式プレイヤーとチャットリプレイを表示します。埋め込みライブチャットで代用しません。
- 共通ヘッダーのAUTO / SIDE / BOTTOM / HIDE、読み上げラベル、キーボード操作を利用できます。
- VODの最前面表示、チャットだけの別窓、チャット再読込には対応していません。元タブへの再生位置の引き継ぎや自動再開も行いません。

## 確認済みの範囲

1.6.0は利用者の実環境で基本動作の確認報告があります。

全体の自動検査は**441件成功・0件失敗**、静的検査も成功しています。アーカイブ関連では、次の点を検査しています。

- 動画ID・開始時刻の検証、公式URLの生成、別窓を開いた後だけ元動画を停止すること。
- 歯車メニューの再表示・差し替え、重複防止、不明・非表示・曖昧な構造で追加しないこと。
- 11言語の起動項目・エラー文・読み上げラベル、ブラジルポルトガル語を含む認識対象のTwitchメニュー。
- Document PiP APIがなくても通常別窓の項目を利用でき、VOD最前面の操作を提供しないこと。
- ライブと共通のヘッダーCSS、36px/24pxの寸法、狭幅時の配置計算、キーボード操作。
- ページ遷移・BFCache・同意取り消し・プレイヤー交換後に古い起動項目や配置操作を無効にすること。
- ポップアップがブロックされたときの案内と再試行、動画やリプレイが見つからない場合の処理。
- 監視・タイマー・追加表示の後処理、ZIPの構成と再現性。

これらはDOM/API代替実装と静的検査の結果です。実サービス上の描画、動画再生、リプレイ同期を網羅した試験ではありません。

## 残る実サービス確認

幅広いアーカイブでのシーク・速度変更・長時間の同期は未完了です。基本動作の確認報告は、以下の詳細項目すべてに合格したことを意味しません。

ブラウザのバージョン、OS、対象アーカイブ、Twitchの表示言語を記録し、通常のTwitchページでリプレイを利用できるアーカイブを基準に確認します。PopChatは1つだけ有効にし、更新後は拡張とTwitchページを再読み込みしてください。

- [ ] 同意前はページを変更せず、有効化後の歯車メニューに追加項目が一つだけ現れる。Twitch標準項目の動作が変わらない。
- [ ] 別窓が正しいアーカイブの現在位置付近で始まり、元動画が停止する。映像と公式リプレイが同じ窓に表示される。
- [ ] 純正VODポップアウトの追加項目からも公式アーカイブページが開く。
- [ ] 前後へのシークやリプレイ内のタイムスタンプ選択を繰り返しても、動画位置とリプレイの対応が保たれる。
- [ ] 一時停止・再開・再生速度変更の後もリプレイが追従する。
- [ ] 画質・音量・ミュートを操作でき、設定メニューやツールチップが隠れない。
- [ ] 元タブを背面にした状態や長時間の視聴でも、別窓の動画とリプレイの更新が続く。
- [ ] 配置切り替え、縦横のサイズ変更、キーボード操作、長い翻訳、200%ズーム、RTL表示で操作部が使える。
- [ ] 開く・配置変更・閉じる操作を繰り返しても項目や表示が重複せず、失敗後に再試行できる。
- [ ] 別アーカイブへの遷移やプレイヤー差し替え後に、前の動画やリプレイを混ぜない。
- [ ] リプレイ非提供・非表示・読み込み失敗時にライブチャットへ置き換わらず、通常のTwitchページへ戻って確認できる。
- [ ] 別窓を閉じた後も元タブが残り、そこで再生を再開できる。
- [ ] ライブ配信の通常ポップアウト・最前面小窓・配置・再読込・チャット別窓・終了時の復元が動作する。

全体の検証範囲は[TESTING.md](TESTING.md)、操作説明は[VOD-PREVIEW.md](VOD-PREVIEW.md)を参照してください。
