# Asset provenance

The extension icon is an original geometric design created for PopChat for Twitch. Its editable vector source is `assets/icon.svg`; the runtime uses the four locally rendered PNG sizes in `extension/icons/`.

The icon was drawn directly as SVG and rendered with Inkscape. It does not include a font, downloaded photo, copied Twitch logo/Glitch, or third-party illustration. The project has no runtime dependence on the drawing tool. This description records how the delivered asset was made; it is not trademark clearance or a guarantee that no similar mark exists.

Store promotional material is prepared separately and is not required by the extension. Actual store screenshots must depict the released extension's real interface; no fixture or illustration should be represented as an actual browser capture.
