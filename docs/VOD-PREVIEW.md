# アーカイブとチャットリプレイ · 1.6.0

Twitchのアーカイブを、公式チャットリプレイと一緒に通常の別窓で表示します。アーカイブの最前面表示には対応していません。ライブ配信の最前面表示は引き続き利用できます。

## 使い方

1. 拡張アイコンの「使い方・設定」で説明を確認し、機能を有効にします。
2. チャットリプレイを利用できるTwitchアーカイブの通常ページを開き、プレイヤーの歯車メニューを開きます。
3. 「ポップアウト（チャットリプレイ付き）」を選びます。現在のアーカイブと再生位置を指定した公式ページが別窓で開き、元動画が一時停止します。Twitch標準のポップアウト項目は変更しません。
4. 別窓のAUTO / SIDE / BOTTOM / HIDEで配置を切り替えます。ヘッダーの見た目、読み上げラベル、←/→・Home/Endによるフォーカス移動はライブと共通です。
5. 視聴を終えたら別窓の×で閉じます。元タブは残るため、必要に応じてそこで再生を再開してください。別窓の再生位置を元タブへ戻す処理や、自動再開は行いません。

`player.twitch.tv`の純正VODポップアウトからは、認識できる歯車メニューの「チャットリプレイ付きでアーカイブを開く」で公式アーカイブページを開けます。純正の埋め込み動画ページ自体にはリプレイを追加しません。

## 表示と操作

- AUTOは窓の形に合わせて右側または下側、SIDEは右側、BOTTOMは下側にリプレイを配置します。
- HIDEはリプレイの表示領域を畳みます。元のリプレイ要素は残り、ほかの配置で表示を戻せます。
- ヘッダーは36px、配置ボタンは24pxを基本とします。狭い幅では余白を調整します。
- チャットだけの別窓、チャット再読込、元アーカイブへ戻る専用ボタンはありません。
- 通常別窓はDocument Picture-in-Pictureを使用しません。最前面への固定は行いません。

## 方式と制約

Twitchの[埋め込み仕様](https://dev.twitch.tv/docs/embed/everything/)では、VODのチャットリプレイはサポートされていません。そのため、公式VODフルページ上のプレイヤーとネイティブリプレイを同じドキュメントに保ち、配置を調整します。拡張が動画とチャットの時刻を独自に同期する方式ではなく、リプレイの再生と更新はTwitchに依存します。

- 起動時は`https://www.twitch.tv/videos/ID`に開始時刻を指定します。別窓のURLにはPopChatの配置を有効にする目印も付きます。
- 既知の構造・ラベルで表示中のメニュー項目を一意に認識できる場合だけ、起動項目を追加します。認識できない場合は、標準項目を変更せずに追加を止めます。[認識対象](NATIVE-MENU-EVIDENCE.md)
- Twitchがそのアーカイブのリプレイを提供していることが前提です。リプレイがない場合にライブチャットで代用したり、チャット履歴を独自に取得したりしません。
- プレイヤーやリプレイの差し替え、ページ遷移、同意の取り消しでは、古い配置や操作を解除します。
- 動画IDと再生位置は別窓を開くために使用し、閲覧履歴として保存しません。チャット本文の抽出・保存、認証トークンの取得は行いません。[プライバシーポリシー](../PRIVACY.md)

## 困ったとき

1. 同じ拡張の旧版や別コピーを無効にし、PopChatを1つだけ有効にしてください。拡張とTwitchページを再読み込みします。
2. 歯車の項目が出ない場合は、Twitchの表示言語と現在のメニュー構造が認識対象か確認してください。
3. 別窓が開かない場合は、ブラウザがTwitchのポップアップをブロックしていないか確認してください。別窓の起動に失敗した場合、元動画は停止しません。
4. 再生やリプレイの更新が止まった場合は、別窓を閉じて元タブで再生を再開してください。通常のTwitchページでもリプレイが使えるか確認してください。

## 確認状況

1.6.0は実環境で基本動作の確認報告があります。自動検査441件と静的検査も成功しています。幅広いアーカイブでのシーク・速度変更・長時間の同期、すべてのブラウザ・言語での実描画は網羅的に確認できていません。

詳しい検査結果と確認手順は[VOD-VALIDATION.md](VOD-VALIDATION.md)と[TESTING.md](TESTING.md)を参照してください。
