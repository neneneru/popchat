## 利用環境での確認手順

1. 拡張を再読み込みし、初回の説明タブ、または拡張アイコンの「使い方・設定」から説明を確認して有効にする。同意前/「今はしない」ではTwitchが変わらないことを確認する。
2. Twitchを再読み込みし、通常配信ページの歯車を開く。
3. 本来の「ポップアウト」の隣に「ポップアウト（最前面）」が一つだけ出るか確認。
4. 本来の項目は通常どおり動作し、追加項目は通常ページから直接最前面小窓を開くか確認。
5. ヘッダーの6操作、上下余白、チャットの再読込と別窓を確認。
6. 小窓の×で映像が戻ること、配信切替後も重複した項目や監視が残らないことを確認。

最前面表示の項目が出ない場合は、元のTwitch項目を変更せずに止める設計です。失敗時に別経路へ自動転送することはありません。
