# PopChat for Twitch 1.6.0

Twitchのポップアウトにチャットを追加します。最前面の小窓は、通常の配信ページの歯車メニューから開きます。

## 導入

1. ZIPを展開します。
2. Chromeは `chrome://extensions`、Edgeは `edge://extensions` を開き、デベロッパーモードをONにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、**manifest.jsonが直下にある展開先フォルダー**を選びます。ソースZIPやこのリポジトリを使う場合は、中のextensionフォルダーを選びます。
4. 初回インストール時は、説明ページが新しいタブで開きます。内容に同意できる場合は「有効にする」を押します。「今はしない」ならTwitchは元のままです。ページを閉じた場合は、拡張アイコンの「使い方・設定」から開き直せます。
5. Twitchページを開きます。既に開いている場合は必要に応じて再読み込みします。

デスクトップ版Chrome / Edgeを対象とし、manifestの最小Chromeバージョンは116です。ライブの最前面表示には[Document Picture-in-Picture](https://developer.chrome.com/docs/web-platform/document-picture-in-picture)への対応が必要です。アーカイブの通常別窓では、このAPIを使用しません。

### 旧版からの更新

小窓を閉じ、同じ拡張の別バージョンや重複したコピーが同時に有効になっていないことを確認してください。有効にするのは1つだけです。古いextensionフォルダーへファイルを追加上書きするのではなく、**フォルダー全体を新版へ入れ替えます**。古いフォルダーを別の場所へ退避し、配布ZIPを展開した新しいフォルダーを元の読み込み場所・同じ名前で置くと、旧版の余分なファイルを残さず更新できます。

その後、拡張機能管理画面で再読み込みを押し、開いているTwitchページもすべて再読み込みしてください。ブラウザに保存したモード・サイズ設定を消す処理は行いません。1.4.0以前から更新した場合も、自動で同意済みにはしません。拡張アイコンの「使い方・設定」を開き、内容を確認して有効にしてください。更新時・拡張の再読み込み時・ブラウザ起動時には説明タブを自動で開きません。1.5.0以降で既に同意している場合は、その選択を引き継ぎます。

## 開き方

通常のTwitch配信ページで、映像の歯車を開きます。

- **ポップアウト**：Twitch本来の操作です。普通のポップアウトが開き、この拡張がチャットを追加します。
- **ポップアウト（最前面）**：この拡張が追加する項目です。通常ページから、映像とチャットの最前面小窓へ直接移します。

最前面の入口は、この歯車メニュー内の1か所だけです。純正ポップアウトを先に開く必要はありません。元の通常タブは開いたままにしてください。小窓の×またはブラウザの「元に戻る」操作で、映像が元の場所へ戻ります。

内部では任意HTMLを表示できるDocument Picture-in-Pictureを使用します。通常の動画専用PiPを変更する機能ではありません。

## アーカイブの開き方

Twitchのアーカイブの歯車メニューで「ポップアウト（チャットリプレイ付き）」を選びます。現在位置付きの公式ページを別窓で開き、元動画を一時停止します。元タブは残ります。

アーカイブのヘッダーはライブと同じ見た目・キーボード操作のAUTO / SIDE / BOTTOM / HIDEです。戻るボタン、チャットだけの別窓、再読込ボタンはありません。別窓を閉じた後は必要に応じて元タブで再生を再開してください。再生位置の戻し渡しや自動再開は行いません。

アーカイブの最前面表示は無効です。[詳しい使い方と検証範囲](VOD-PREVIEW.md)

## ライブ小窓の操作

ライブ・アーカイブともヘッダーは36px、ボタンは24pxを基本とし、上下に余白を設けています。

**AUTO / SIDE / BOTTOM / HIDE / 再読込 / 別窓**

- AUTO：ウィンドウの形に合わせて右または下へチャットを配置
- SIDE：右側へ配置
- BOTTOM：下側へ配置
- HIDE：チャットだけを隠す。ほかの配置を押すと戻ります
- 再読込：公式チャットを再読み込み
- 別窓：公式チャットだけを別ウィンドウで開く

HIDEではチャットiframeを保持します。ボタンはTab、Enter/Spaceで操作でき、配置ボタン間は←/→・Home/Endでもフォーカス移動できます。非常に狭い幅では文字と横の余白を縮め、必要なら横スクロールします。

## 言語

日本語・英語・韓国語・簡体字中国語・スペイン語・ドイツ語・フランス語・ブラジルポルトガル語・ロシア語・アラビア語・インドネシア語に対応します。表示はブラウザのUI言語に従い、対象外は英語になります。AUTO / SIDE / BOTTOM / HIDEは共通表示で、説明・読み上げラベルを翻訳します。アラビア語でもSIDEは右側を表し、配置ボタンの順番は共通です。

各言語の導入・操作説明は[docs/locales](locales/)にあります。拡張の表示言語とTwitch側の表示言語は別です。1.6.0では、ブラジルポルトガル語を含む10言語のTwitchポップアウト項目を認識します。インドネシア語の拡張表示は、英語など認識対象のTwitchメニューと組み合わせて使えます。未知の文言や構造では追加項目を表示しません。純正ポップアウトへのチャット追加はこのメニュー照合に依存しません。[照合の根拠と範囲](NATIVE-MENU-EVIDENCE.md)

## 表示されない場合

1. PopChatを1つだけ有効にし、旧版や重複したコピーを無効にしてください。拡張機能と、開いているTwitchページをすべて再読み込みします。
2. 通常の配信ページで、Twitchの歯車メニューを開いてください。チャットだけのページ、VOD、クリップ、純正ポップアウト内には最前面項目を追加しません。
3. Twitchのメニュー構造が確認済みの形式と一致する場合だけ項目を追加します。構造が変わった場合、別の場所へ代替ボタンを出したり、本来の項目を書き換えたりはしません。

ライブのチャットの表示・ログインで困った場合は「再読込」「別窓」を使えます。送信・ログイン状態の引き継ぎはTwitchとブラウザ設定に依存します。アーカイブでリプレイが表示されない場合は、通常のTwitchページでリプレイを利用できるか確認してください。

## 制約

- 元タブを閉じる・再読み込み・別ページへ移動すると、最前面小窓も閉じます。
- 最前面小窓へ移すのは同じvideo要素です。Twitch独自の品質設定、字幕の描画UI、広告やエラーのオーバーレイは小窓に付かない場合があります。画質などは移動前に設定してください。
- Twitchが動画を差し替えた場合は安全に元へ戻し、必要なら歯車から開き直します。
- Firefox、モバイル、クリップは対象外です。VODは公式リプレイ付きの通常別窓に対応し、最前面は無効です。

## プライバシー

権限はstorageのみ、対象はwww.twitch.tvとplayer.twitch.tvのHTTPSページです。保存するのは表示モード・小窓サイズ・有効化への同意記録だけです。認証情報、チャット履歴、閲覧履歴は保存しません。公式チャットの内容を取得・独自解析しません。独自の外部サーバーや解析機能はありません。映像と公式チャットは通常どおりTwitchと通信します。[詳細](../PRIVACY.md)

### 無効化

拡張アイコンの「使い方・設定」で説明ページを開き、「無効にする」で同意を取り消せます。追加チャットと歯車項目を取り除き、最前面小窓の動画を元へ戻します。表示設定は保持し、再度同意するまでページの情報を処理しません。アーカイブの追加ヘッダーと配置変更も解除します。「別窓」で自分で開いた公式チャットやアーカイブのウィンドウは、自動では閉じません。

## 検証

1.6.0は利用者の実環境で基本動作の確認報告があります。自動検査441件と静的検査も成功しています。自動検査はDOM/APIの代替実装を使用しており、全言語の実描画や、幅広いアーカイブでのシーク・速度変更・長時間同期を保証するものではありません。[検証範囲](TESTING.md)

## 開発

ソース版ZIPの全テストにはNode.js 20以上とPython 3が必要です。第三者パッケージの追加は不要です。通常利用にはNode.jsもPythonも不要です。

```sh
npm test
npm run check
npm run package
```

ZIP生成はPython 3の標準ライブラリを使用し、dist/に実行用ZIPとソースZIPを出力します。Twitchとは提携・関連のない非公式の拡張機能です。
